## 👨‍💻 About This Portfolio

This is my **personal developer portfolio** — a fully animated, 3D-inspired, single-page website built with pure **HTML, CSS & JavaScript**. It fetches all data live from the GitHub API, so it's always up to date with my latest projects and stats.

> ✨ No frameworks. No build tools. Just clean, handcrafted code.

---

## 🔥 Features

| Feature | Description |
|--------|-------------|
| 🎆 **3D Particle Background** | Animated constellation network that reacts to theme changes |
| 🌙☀️ **Dark / Light Mode** | Smooth toggle with preference saved via `localStorage` |
| 📦 **Live GitHub Repos** | All repositories fetched in real-time from the GitHub API |
| 📊 **Language Breakdown** | Animated progress bars showing top coding languages |
| 🏆 **GitHub Achievements** | Showcasing YOLO, Pull Shark, Starstruck & more |
| 🔍 **Scroll Spy Nav** | Active nav link highlights as you scroll through sections |
| 📬 **Contact Form** | Pre-fills your email client — works on fully static hosting |
| ✨ **Ripple Effects** | Every button click triggers a satisfying ripple animation |
| 📱 **Fully Responsive** | Looks great on mobile, tablet & desktop |
| ⚡ **Zero Dependencies** | No npm, no bundlers — just one HTML file |

## 📁 Project Structure

```
📦 Portfolio/
 ┣ 📄 index.html       ← The entire portfolio (HTML + CSS + JS)
 ┗ 📄 README.md        ← You are here
```

> Everything lives in a single `index.html` file — no dependencies, no build steps, just open and go.

---

## 🚀 Getting Started Locally

```bash
# 1. Clone this repository
git clone https://github.com/puspendugorai-coder/Portfolio.git

# 2. Navigate into the folder
cd Portfolio

# 3. Open in your browser
open index.html
# or just double-click index.html in your file explorer
```

No installation required. No `npm install`. It just works. ✅

## 🌍 Deployment

This portfolio is hosted for free on **GitHub Pages**.

| Platform | URL |
|----------|-----|
| 🐙 GitHub Pages | [puspendugorai-coder.github.io/Portfolio](https://puspendugorai-coder.github.io/Portfolio/) |

To deploy your own fork:
1. Fork this repo
2. Go to **Settings → Pages**
3. Set source to `main` branch → `/ (root)`
4. Your site will be live at `https://<your-username>.github.io/Portfolio/`
